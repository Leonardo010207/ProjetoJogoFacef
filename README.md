um jogo 2d desenvolvido no construct 3 onde você controla um personagem que tenta sobreviver a um ataque de uma infestação de criaturas, efetuando disparos contra os mesmos e adquirindo pontos a cada eliminação

## Demonstração
![Print Aplicação](https://github.com/user-attachments/assets/24f74faa-1269-48e3-a567-4c95940df33d)

## Tecnologias utilizadas
- [Construct 3] https://editor.construct.net/
- Photoshop para sprites

## Funcionalidades
-Controle fluido do personagem com o teclado
-Controle de visao com mouse
-Geração infinita de inimigos (fantasmas)
-Sistema de pontuação e recorde
